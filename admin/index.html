Veritabanı bağlı değil

Yönetim panelinin çalışması için Vercel projenize ücretsiz Upstash Redis veritabanının bağlanması gerekiyor.

  1. Vercel'de givanibridal1 projesini açın → Storage sekmesi.
  2. Create Database → Upstash for Redis → ücretsiz plan → bölge olarak Frankfurt (eu-central-1).
  3. Connect Project ile givanibridal1 projesine bağlayın.
  4. Deployments sekmesinden son yayını Redeploy edin.
